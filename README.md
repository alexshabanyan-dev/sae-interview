# SAE Interview

Конспекты и задачи для подготовки к собеседованиям: JavaScript, темы с карточками и подробными страницами (например, замыкания).

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Статика попадает в каталог `dist/` — его можно отдавать через Nginx или разместить под префиксом пути (см. `base` в Vite и `basename` у React Router).

## Стек

React, TypeScript, Vite, Mantine v8, React Router.
