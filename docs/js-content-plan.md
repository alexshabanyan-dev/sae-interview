# План контента: только JavaScript

Документ для **планирования** статей/задач в разделе «JavaScript / TypeScript» приложения. Обновляй статусы по мере работы.

Формат реализации каждой темы (как у существующих): страница на `JsTopicDetailLayout`, теория секциями, блок Q&A, блок задач, маршрут в `App.tsx`, карточка в `JsTopicsPage.tsx`.

## Заметки

- **TypeScript** как отдельный крупный блок (типы, generics, utility types) можно вынести в отдельный план или в конец этого файла секцией «TS», если решишь разделять «чистый JS» и TS.
- Дубли с Event Loop / промисами лучше закрывать **отсылками**, а не копировать главы.
- Количество задач: ориентир как у других тем (много — для «больших» тем, меньше — для узких вроде `AbortController`).
